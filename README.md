# birthday-paradox
Симуляция парадокса дней рождения.

Подробнее о самом парадоксе: https://ru.wikipedia.org/wiki/Парадокс_дней_рождения?ysclid=mukhnguh3x7113705

Симуляция подтверждает: коллизия в хеш-пространстве размера N 
ожидается через ~√(πN/2) шагов. Для 128-битного хеша это ~2^64.

В коде генерируется случайные числа в заданном диапазоне (степень двойки). Генерация происходит до первого совпадения. Эксперимент проводится заданное число раз (В коде это 200), затем вычисляется среднее арифметическое и взвешенное. Ниже приведен вывод программы для 8,12,16 и 20-битных хэшей.

Бит: 8, вариантов: 256
  Среднее число шагов до коллизии: 20.04
  Теоретическая оценка (√(πN/2)):  20.05
  Наивная оценка (√N):             16.0

Бит: 12, вариантов: 4096
  Среднее число шагов до коллизии: 79.18
  Теоретическая оценка (√(πN/2)):  80.21
  Наивная оценка (√N):             64.00

Бит: 16, вариантов: 65536
  Среднее число шагов до коллизии: 320.05
  Теоретическая оценка (√(πN/2)):  320.85
  Наивная оценка (√N):             256.00

Бит: 20, вариантов: 1048576
  Среднее число шагов до коллизии: 1220.60
  Теоретическая оценка (√(πN/2)):  1283.39
  Наивная оценка (√N):             1024.00

* предполагается что хэш-функция идеальна, то есть имеет равномерное распределение значений
